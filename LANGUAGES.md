# Languages and accessibility

Code: `flutter_ui/lib/src/l10n.dart` (the language), `l10n_ui.dart` (the picker), `l10n/l10n_<code>.dart` (the tables),
`a11y.dart` (accessibility options), `refresh.dart`. Tables are generated by `tools/gen_l10n.py`; `tools/check_l10n.py` checks them.

## Language

Offered: English, Español, Français, Deutsch, Português. The choice is kept on the device (not per profile) under `pek_language_v1`:
`system` (follow the device, English when the device language is not offered) or a language code.

- **First launch:** the language question is the first screen of `OnboardingFlow`, before the welcome tour. Tapping a language changes the
  screen at once; **Continue** keeps the choice (also "System default"), so it is not asked again. An install that was updated from an
  older version is not asked (it keeps the device language); Settings > Language changes it.
- **Settings > Language:** the same list. Changing it repaints every screen without closing the ones that are open (`refreshWholeApp`).
- **Material texts** (dialogs, pickers, tooltips) follow the language through `flutter_localizations`.

### How text is translated

The English text is the key: `'Sign in later'.tr`, or `'{n} new'.trp({'n': 3})` for text with a number. A string with no entry stays
English, so screens can be translated one at a time and nothing ever shows a blank or a key name.

Translated so far: the language and accessibility screens, the welcome tour, the layout question, sign in, the Settings list, the main
menus (phone bar, TV side menu, Simple layout bar and chips), the exit dialog and the screen-reader labels. **Not translated yet:** the
inside of most other screens (library, player, music, Settings pages below the list, plugin store). Library data (titles, synopses),
plugin text and skin text are never translated by the app. Right-to-left languages are not offered: the D-pad navigation and the skin
layouts assume left-to-right.

### Adding a translation

1. Wrap the text in the screen: `Text('Hello')` becomes `Text('Hello'.tr)` (drop a `const` that now sits in front of it).
2. Add one row to `ROWS` in `tools/gen_l10n.py`: the English text, then Spanish, French, German, Portuguese.
3. `python3 tools/gen_l10n.py flutter_ui/lib/src/l10n`, then `python3 tools/check_l10n.py`. CI runs the check and fails on a missing
   or mistyped entry. `flutter test test/l10n_test.dart` checks the same from Dart.

### Adding a language

Add an `AppLanguage` to `L10n.languages`, a column to `ROWS` and the code to `LANGS` in `gen_l10n.py`, and import the new table in
`l10n.dart`. Have a native speaker read it: the tables were written without one. Voice search still recognises English only (the
bundled speech model), and the Android system texts (splash, notification, widget) are not translated yet.

## Accessibility

Settings > Accessibility (device-wide):

- **Text size:** Normal / Large / Larger / Largest (100 / 115 / 130 / 150 %) on top of the device's font size, capped at 200 % in total.
- **Reduce motion:** sets `MediaQuery.disableAnimations`, the same switch as Android's "remove animations". The focus box snaps instead
  of easing; the activity display and skin buttons already honoured the system switch.
- **Stronger focus outline:** a thick, full-contrast ring on the selected item on phones and TVs.

Screen readers (TalkBack): `PekFocusable` is a button with a focus state; headings (`Heading`, `Section`) are marked as headings;
switch rows say on / off; poster cards read as one item ("Title, year, rated 8 out of 10, in your library, 40 percent watched",
worked out only while a screen reader is on); the online / offline dot says which. Not done yet: caption styling for subtitles (size,
background) — mpv draws them on the normal video path, so it needs the Kotlin side as well — and a check of every skin's contrast.
